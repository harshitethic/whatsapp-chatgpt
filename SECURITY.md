# Security guidance

Never upload, commit or post API keys, WhatsApp session credentials, QR session payloads or private messages. Report security concerns privately to contact@harshitethic.com.

Rotate any credential that was previously committed: deleting it from the latest commit does not remove it from Git history.

This is a historical sample with outdated dependencies and no production-grade authentication, quotas or abuse controls. Do not expose it as a public service without a fresh dependency review, test coverage and operational safeguards.
